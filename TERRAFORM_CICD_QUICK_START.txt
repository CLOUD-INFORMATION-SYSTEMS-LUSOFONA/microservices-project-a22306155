📋 WORKFLOW SIMPLES

1. Código Muda em infra/terraform/

2. Abres Pull Request (PR)
   └─ GitHub Actions automático:
      ✅ terraform fmt -check
      ✅ terraform validate
      ✅ terraform plan
      └─ Comenta no PR com resultado
   └─ Se falhar → Can't merge
   └─ If OK → Ready to review

3. Merge PR para main
   └─ GitHub Actions automático:
      ✅ terraform apply (SEM -auto-aprove em produção real)
      ❌ Apply só acontece em main (nunca em branches)

2. DEVELOPER WORKFLOW

   a) Feature branch
      git checkout -b feature/add-new-service
      vim infra/terraform/main.tf (faz mudanças)
      git commit -m "add new service"
      git push

   b) GitHub (automático)
      PR aberto
         ↓
      terraform-plan.yml trigger
         ↓
      ✅ fmt check
      ✅ validate
      ✅ plan
         ↓
      Comment no PR:
      "Plan: 3 to add, 0 to change, 0 to destroy"

   c) Review
      You: Lês o plan no PR
      You: Reviews código
      You: Approves PR

   d) Merge
      You: Merge para main
         ↓
      GitHub Actions (automático)
         ↓
      ✅ terraform apply
      ✅ Captura outputs
      ✅ Ansible deploy
      ✅ Health checks
         ↓
      Infrastructure updated + services deployed

🔍 DEBUGGING

Onde ver logs?
  GitHub → seu repo → Actions tab → Select workflow

Plan falha?
  Review PR comment com erro específico
  Fix localmente, git push novamente

Apply falha?
  Check GitHub Actions logs
  ssh para EC2, docker compose logs

Health checks falham?
  Services ainda estão iniciando
  Aguarda 1-2 min, refresh
